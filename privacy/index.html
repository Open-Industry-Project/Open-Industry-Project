Privacy: part libraries and publishing

What happens to your information when you get parts from a part library, and when you publish a part to the listed library. The Open Industry Project is maintained by Automation Standard LLC.

Getting parts

Get parts reads each library's index and downloads the parts you add from the address the library is served from. The official libraries are served from parts.openindustryproject.org by Cloudflare, which handles each request as any web host does. The project keeps no record of who reads a library or downloads a part, and you need no account to do either. A library you add yourself is read from its own host, under that host's terms.

Signing in with GitHub to publish

Publishing a part needs a GitHub account, because your part is sent as a pull request under it. When you sign in, GitHub shows a code that you enter on github.com. The sign-in passes through a small service at signin.openindustryproject.org that only forwards the two sign-in requests to GitHub. It stores nothing and keeps no logs.

The access token GitHub gives the app is kept in your browser's storage on this device, or in the desktop app's, and is sent only to GitHub. The app uses it to fork the parts repository, add your part on a branch, open the pull request and read how its review is going. Sign out in the Publish dialog to forget it, and revoke the app at any time in your GitHub settings under Applications.

What becomes public

The parts repository is public on GitHub. Your pull request, your GitHub account name, the part and the description you wrote are visible there to anyone, under GitHub's own privacy terms. Once a part is listed, the library's index names your GitHub account or organization as its publisher, and the part's files are served to anyone who adds it.

A listed version is kept for good, because projects that added it keep using it and every later version of the app is tested against it. That includes the publisher name listed with it.

Training AI models

A listed part is public under the MIT License for its code and CC BY 4.0 for its models, which allow anyone to use it for any purpose, training AI models included. Do not publish a part you would not share on those terms. Nothing from your projects, rooms or parts shelf is ever used for training.

Removal and questions

To report a listed part that infringes your rights, or to ask about your information, write to parts@openindustryproject.org. A part reported credibly as infringing is removed from its library and its files deleted within 7 days. Projects that already added it keep their own copies, which the project cannot reach.
